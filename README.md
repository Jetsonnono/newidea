# Helio-Matrix 3D

交互式参数化建筑可视化 · **向日葵矩阵·高原钙钛矿零碳驿站**

Vite + Three.js 纯代码几何建模，含日照追光、发电功率、视角预设与 4K 截图导出。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

## 功能

- **三层流线型基座**：白色混凝土 + 覆土保温、下沉庭院、V2G 坡道与充电桩位
- **双曲面网壳中庭**：钢结构 diagrid + 琥珀 / 青金石色渐变钙钛矿 BIPV，地面彩色光斑
- **24 片仿生追光花瓣**：屋顶螺旋 16 + 南立面 8，蓝紫晶格与金色汇流条，实时朝向太阳法线
- **时间滑块 06:00–20:00**：平行光日照轨迹、阴影与发电功率（kW）
- **视角预设**：鸟瞰 / 人视仰拍 / 中庭室内 / 结构爆炸 / 白模线框
- **控制台可隐藏**，支持 **4K 纯白 / 透明 PNG** 导出

## 技术栈
